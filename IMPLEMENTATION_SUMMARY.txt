Neural-Symbolic Weight Balance:
  0.9 / 0.1  → Very neural-heavy (best if symbolic rules weak)
  0.8 / 0.2  → Neural-biased (conservative)
  0.7 / 0.3  → Balanced (recommended starting point)
  0.6 / 0.4  → Symbolic-biased (aggressive)
  0.5 / 0.5  → Equal (only if rules/constraints are very good)

Score Fusion Methods:
  'weighted_sum'  → 0.7 * neural + 0.3 * symbolic (recommended)
  'product'       → neural * symbolic (more conservative)
  'mlp'          → Learned fusion (requires fine-tuning)

Problem: No improvement in metrics
Solution:
  1. Check if rules are being applied (metrics.rules_applied > 0)
  2. Validate rule definitions
  3. Increase symbolic weight
  4. Review constraint accuracy

Problem: Performance degradation
Solution:
  1. Reduce symbolic weight
  2. Review constraints for incorrectness
  3. Disable specific rules
  4. Check entity type assignments

Problem: Memory issues
Solution:
  1. Use post-processing instead of in-training
  2. Reduce number of rules
  3. Use simpler fusion method (weighted_sum)

Problem: Rules not applying
Solution:
  1. Verify intermediate triples exist
  2. Check rule body relations
  3. Lower confidence threshold
  4. Add transitivity markers
